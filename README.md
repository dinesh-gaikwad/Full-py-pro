# ✨ Magical Tools Hub

A collection of 9 interactive web tools built with **HTML, CSS, and JavaScript** featuring magical animations and glassmorphism UI.

## 🚀 Live Demo
Open `index.html` in your browser to launch the dashboard.

## 🛠️ Tools Included

| # | Tool | Description |
|---|---|---|
| 1 | **Data Filter** | Filter and sort data instantly with search functionality |
| 2 | **Snake Game** | Classic retro snake game with smooth controls |
| 3 | **Resume Editor** | Build and preview professional resumes |
| 4 | **Data Converter** | Convert between JSON, CSV, XML formats |
| 5 | **Translator** | Multi-language text translator |
| 6 | **Ludo** | Interactive ludo game with dice roll |
| 7 | **Magic Watch** | Real-time clock with visual effects |
| 8 | **Magic Card** | Interactive card prediction game |
| 9 | **Validation** | Form validation toolkit for inputs |

## ✨ Features

- **Magical UI**: Glassmorphism design with gradient backgrounds and particle effects
- **3D Hover Animations**: Cards lift and rotate on hover with shine effect
- **Smooth Transitions**: Teleport animation when navigating between pages
- **Responsive Grid**: Auto-adjusts to mobile, tablet, and desktop screens
- **No Dependencies**: Pure HTML, CSS, JS - no frameworks needed
